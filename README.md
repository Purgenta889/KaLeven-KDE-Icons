# KaLeven KDE Icons
This icon set combines the sleek blue folders of yeyushengfan258's [Win11](https://store.kde.org/p/1546069) with 2O48's [Kaze](https://github.com/2O48/Kaze). It replaces:

- The default file manager icon
- The default folder icon
- The default icons for bookmarked folders

## Installation
**[Download here!
](https://github.com/Purgenta889/KaLeven-KDE-Icons/releases)**

### Alternative Method

Run this command to download everything from this repository:
```
git clone https://github.com/Purgenta889/KaLeven-KDE-Icons.git
```
Inside the newly created folder, place both variants of the icon theme in either directory:

- For per-user: `~/.local/share/icons/`  
- For system-wide: `/usr/share/icons/`
